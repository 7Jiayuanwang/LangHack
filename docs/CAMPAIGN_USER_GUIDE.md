# 活动发布与统计功能 - 使用指南

## 概述

本系统提供完整的活动发布与统计功能，支持管理员创建学习活动、学生自主报名参与、自动数据采集、多维度排名统计等功能。

---

## 管理员操作手册

### 1. 创建活动

#### 1.1 进入活动管理页面

1. 登录管理后台
2. 点击侧边栏"活动管理"菜单
3. 点击"创建活动"按钮

#### 1.2 填写基本信息

**必填字段**：
- **活动标题**：简洁明确的标题（如"2024春季学习竞赛"）
- **活动描述**：详细说明活动内容和规则
- **开始时间**：活动开始日期和时间
- **结束时间**：活动结束日期和时间

**配置项说明**：

**完成规则**
- **ANY（完成任意任务）**：学生完成任意一个任务即算完成活动
- **ALL（完成所有任务）**：学生必须完成所有任务才算完成活动
- **THRESHOLD（完成指定数量）**：学生需要完成指定数量的任务（推荐，默认选项）

**报名模式**
- **AUTO（自动报名）**：符合条件的学生自动加入活动
- **MANUAL（学生自主报名）**：学生需要手动提交报名申请
- **INVITE_ONLY（仅邀请）**：仅管理员邀请的学生可以参加，需要审核

**报名范围**
- **ALL（全部）**：所有学生都可以报名
- **COLLEGE（学院）**：限制指定学院的学生
- **GRADE（年级）**：限制指定年级的学生
- **CLASS（班级）**：限制指定班级的学生
- **CUSTOM（自定义）**：手动选择允许报名的学生

**隐私设置**
- **显示分数**：勾选后学生可以看到自己的具体分数
- **显示排名**：勾选后学生可以看到自己的排名位置

#### 1.3 配置任务

在活动表单中点击"添加任务"按钮，配置任务内容：

**任务类型**
- **READING_TIME（阅读时长）**：统计学生阅读文章的时长
- **WORD_LEARNING（单词学习）**：统计学生学习的单词数量
- **TEXT_UPLOAD（文章上传）**：统计学生上传的文章数量
- **FEEDBACK（问题反馈）**：统计学生提交的反馈数量
- **AI_QA（AI问答）**：统计学生使用AI问答的次数
- **MANUAL（手动录入）**：需要管理员手动录入数据

**任务配置**
- **任务名称**：任务的描述性名称
- **目标值**：完成任务需要达到的数值（如阅读60分钟、学习50个单词）
- **得分**：完成任务可获得的分数
- **必做/选做**：标记任务是否必须完成
- **自动采集**：是否自动从系统采集数据（手动录入任务不支持）

#### 1.4 保存并启动活动

1. 点击"保存"按钮，活动创建成功，状态为"草稿"
2. 检查活动配置无误后，点击"启动活动"按钮
3. 活动状态变为"进行中"，学生即可看到并报名

### 2. 活动管理

#### 2.1 查看活动列表

在活动列表页面可以：
- 按状态筛选活动（草稿/进行中/已结束/已归档）
- 搜索活动标题或描述
- 查看活动基本信息和参与人数

#### 2.2 编辑活动

1. 点击活动行的"编辑"按钮
2. 修改活动信息或任务配置
3. 保存更改

**注意**：进行中的活动不建议修改核心规则（如完成规则、任务配置），可能影响已参与学生的数据。

#### 2.3 结束活动

1. 点击活动行的"结束"按钮
2. 确认结束活动
3. 系统自动执行最后一次数据采集
4. 活动状态变为"已结束"，学生无法继续报名

#### 2.4 删除活动

1. 点击活动行的"删除"按钮
2. 确认删除操作
3. 活动及相关数据将被永久删除

**警告**：删除操作不可恢复，请谨慎操作。

---

### 3. 报名管理

#### 3.1 查看报名列表（仅 INVITE_ONLY 模式）

1. 进入活动详情页
2. 点击"报名管理"标签
3. 查看待审核、已通过、已驳回的报名申请

#### 3.2 审核报名

**批准报名**：
1. 在"待审核"标签页找到申请
2. 点击"批准"按钮
3. 学生状态变为"已通过"，可以参与活动

**驳回报名**：
1. 在"待审核"标签页找到申请
2. 点击"驳回"按钮
3. 填写驳回原因
4. 确认驳回

#### 3.3 批量添加参与者

1. 点击"批量添加"按钮
2. 选择要添加的学生（支持批量选择）
3. 确认添加
4. 学生自动加入活动，无需审核

**适用场景**：管理员指定某些学生必须参加活动。

---

### 4. 统计与排名

#### 4.1 查看活动概览

在活动详情页的"统计"标签，可以看到：
- 总参与人数
- 已报名人数
- 任务完成情况
- 整体完成率

#### 4.2 查看排名

**个人排名**：
- 显示所有参与学生的排名
- 支持分页查看
- 显示学生姓名、班级、得分、完成任务数
- 前三名显示金银铜牌徽章

**班级排名**：
- 按班级聚合统计
- 显示班级总分、平均分、参与人数
- 按总分排序

**学院排名**：
- 按学院聚合统计
- 显示学院总分、平均分、参与人数
- 按总分排序

#### 4.3 手动触发数据采集

系统每小时自动采集一次数据，如需立即更新排名：

1. 点击"手动采集"按钮
2. 等待系统完成数据采集（通常5-30秒）
3. 刷新页面查看最新排名

**注意**：频繁手动采集会增加系统负载，建议仅在必要时使用。

---

### 5. 数据录入与导出

#### 5.1 手动录入单条数据

适用于手动录入类型的任务或补录数据：

1. 进入活动详情页的"手动录入"标签
2. 选择任务类型
3. 搜索并选择学生
4. 填写数值和备注
5. 点击"提交"按钮

#### 5.2 Excel批量导入

适用于批量录入大量数据：

1. 点击"批量导入"按钮
2. 下载Excel模板
3. 按模板格式填写数据（学号、姓名、数值、备注）
4. 上传填写好的Excel文件
5. 查看导入结果（成功数、失败数、错误详情）

**Excel模板格式**：
| 学号 | 姓名 | 数值 | 备注 |
|------|------|------|------|
| 2021001 | 张三 | 60 | 完成阅读任务 |
| 2021002 | 李四 | 55 | |

**导入注意事项**：
- 学号必须在系统中存在
- 数值必须为正数
- 单次导入建议不超过1000行
- 支持 .xlsx 和 .xls 格式
- 导入失败的行会显示具体错误原因

#### 5.3 导出活动数据

导出完整的活动数据，包括所有参与者的详细信息：

1. 在活动列表或详情页点击"导出数据"按钮
2. 选择导出格式（Excel或CSV）
3. 系统生成并下载文件

**导出内容包括**：
- 学生基本信息（学号、姓名、班级）
- 任务完成情况（每个任务的完成值）
- 总得分和排名

#### 5.4 导出排名数据

导出指定维度的排名数据：

1. 在统计页面点击"导出排名"按钮
2. 选择排名维度（个人/班级/学院）
3. 选择导出格式（Excel或CSV）
4. 系统生成并下载文件

### 6. 常见问题

**Q1：为什么学生看不到活动？**
- 检查活动状态是否为"进行中"
- 检查学生是否符合报名范围限制
- 检查 feature toggle 是否启用（`student.campaigns`）

**Q2：为什么排名数据没有更新？**
- 系统每小时自动采集一次数据
- 可以手动点击"手动采集"按钮立即更新
- 检查任务是否配置为"自动采集"

**Q3：如何修改已结束的活动？**
- 已结束的活动不能修改
- 如需修改，先将活动状态改回"草稿"或"进行中"
- 修改后重新结束活动

**Q4：Excel导入失败怎么办？**
- 检查Excel格式是否正确（使用提供的模板）
- 检查学号是否存在于系统中
- 查看错误详情了解具体失败原因
- 修正错误后重新导入

**Q5：如何删除误报名的学生？**
- 在报名管理页面找到该学生
- 点击"驳回"或"删除"按钮
- 学生将从活动中移除

## 学生端使用指南

### 1. 查看可报名活动

1. 登录学生端
2. 点击底部导航栏"活动"菜单
3. 查看当前可报名的活动列表

### 2. 报名参加活动

1. 点击活动卡片查看详情
2. 阅读活动说明和任务要求
3. 点击"立即报名"按钮
4. 等待系统处理（INVITE_ONLY模式需要等待审核）

**报名限制提示**：
- 如果不符合报名条件，系统会显示具体原因
- 常见原因：不在参与范围内、活动已满员、活动已结束

### 3. 查看我的活动

1. 点击"我的活动"标签
2. 查看已报名的活动列表
3. 查看当前进度和排名

### 4. 查看活动进度

1. 点击活动卡片进入详情页
2. 点击"我的进度"按钮
3. 查看以下信息：
   - 总得分
   - 已完成任务数
   - 我的排名（如果活动开启了排名显示）
   - 各任务完成情况（进度条显示）

### 5. 退出活动

1. 进入活动详情页
2. 点击"退出活动"按钮
3. 确认退出
4. 退出后数据将被清除，无法恢复

**注意**：退出活动前请三思，退出后将失去已获得的分数和排名。

## 系统配置

### Feature Toggle 配置

在系统配置表中添加以下配置：

```sql
INSERT INTO system_config (config_key, config_value, description)
VALUES 
  ('admin.campaigns', 'true', '管理员活动管理功能'),
  ('student.campaigns', 'true', '学生活动功能');
```

### 定时任务配置

系统自动运行以下定时任务，无需手动配置：

**每小时自动采集数据**（cron: `0 3 * * * ?`）
- 采集所有进行中活动的数据
- 更新排名信息
- 更新任务完成状态

**每天自动结束到期活动**（cron: `0 0 2 * * ?`）
- 检查所有进行中的活动
- 自动结束已到期的活动
- 执行最后一次数据采集

**每天清理过期缓存**（cron: `0 0 3 * * ?`）
- 清理已归档活动的缓存
- 释放内存资源

### 缓存配置

系统使用 Spring Cache 进行缓存优化：

**缓存区域**：
- `campaign_ranking`：个人排名缓存（5分钟TTL）
- `campaign_overview`：活动概览缓存
- `campaign_stats`：统计数据缓存

**缓存策略**：
- 查询时自动缓存
- 数据采集后自动清除缓存
- 手动触发采集时清除所有缓存

## 性能优化建议

### 1. 活动规模建议

- **小型活动**（<100人）：无特殊配置，正常使用
- **中型活动**（100-500人）：建议手动采集间隔>10分钟
- **大型活动**（>500人）：
  - 考虑分批创建活动
  - 增加服务器资源
  - 延长自动采集间隔

### 2. Excel导入建议

- 单次导入不超过1000行
- 大批量数据分多次导入
- 避免在高峰期进行批量导入

### 3. 排名查询建议

- 利用缓存机制，避免频繁刷新
- 大型活动建议只查看前100名
- 使用分页功能，不要一次加载全部数据

## 附录

### A. 活动状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|----------|
| DRAFT（草稿） | 活动创建后的初始状态 | 编辑、启动、删除 |
| ACTIVE（进行中） | 活动正在进行 | 编辑、结束、查看统计 |
| ENDED（已结束） | 活动已结束 | 归档、查看统计、导出数据 |
| ARCHIVED（已归档） | 活动已归档 | 查看统计、导出数据 |

### B. 任务类型数据源

| 任务类型 | 数据来源 | 采集逻辑 |
|---------|---------|---------|
| READING_TIME | text_learning_records 表 | 统计时长（分钟） |
| WORD_LEARNING | vocabulary_books 表 | 统计单词数量 |
| TEXT_UPLOAD | texts 表 | 统计上传文章数 |
| FEEDBACK | feedback_records 表 | 统计反馈次数 |
| AI_QA | ai_qa_usage_logs 表 | 统计使用次数 |
| MANUAL | campaign_manual_records 表 | 手动录入数据 |

### C. 权限要求

| 功能模块 | 所需角色 | 接口前缀 |
|---------|---------|---------|
| 活动管理 | ADMIN | `/api/admin/campaigns/**` |
| 学生端 | USER 或 STUDENT | `/api/student/campaigns/**` |
