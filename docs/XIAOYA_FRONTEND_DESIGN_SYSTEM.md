# 小芽全站前端设计系统与迁移记录

## 目标与边界

将 `feat/learning-agent-mvp` 中小芽的温暖、清爽、鼓励式视觉语言扩展到全站。学生端突出陪伴感；教师、管理员和运维端采用同一品牌色与组件规范，但以任务效率和数据可读性为先。阅读、视频、考试等沉浸页面不应被装饰或悬浮入口遮挡。

本轮只改前端视觉、布局与可访问性，不改 API、路由权限、功能开关、学习数据或 Flyway。智能体功能分支尚未合入 `develop`；后续合并时，应复用此处设计变量和 `XyMascot` 的形象，避免产生两套小芽样式。

## 分层架构

1. **设计变量**：`frontend/src/styles/xiaoya-theme.css` 定义 `--xy-*` 语义变量，并映射现有 `--primary-*`、`--bg-*`、`--text-*` 与 Element Plus 变量。页面新增样式应直接使用 `--xy-*`。
2. **基础组件**：`frontend/src/components/ui/` 当前包含 `XyPageHeader`（`default` / `hero` / `compact`）、`XySurface` 和 `XyMascot`。现有 Element Plus 组件继续承担表单、表格和弹窗交互；基础组件负责品牌外观，不复制业务逻辑。
3. **布局外壳**：学生端 `student/Layout.vue` 与其他角色的 `shared/MobileLayout.vue` 保持各自路由和导航逻辑，仅共享设计变量、导航视觉与可访问性规则。不要为了统一外观直接合并两套业务布局。
4. **页面类型**：内容发现与学习首页使用柔和 hero；阅读/练习保持专注；教师工作台使用中等密度；管理和运维页面使用紧凑标题、清晰筛选区和高密度数据表。

### 视觉规则

- 品牌主色：森林绿 `--xy-brand-600`；高亮、悬浮和大面积背景使用薄荷绿阶。成功、警告、错误与信息色保留各自语义。
- 底色为暖白和浅薄荷绿；白色内容面板使用细边框与低强度阴影。圆角按 `10 / 16 / 24px` 三档使用。
- 品牌渐变留给 hero 与最重要的行动按钮；表格、长文本和复杂表单保持平实。
- 装饰性小芽设置 `aria-hidden`；有独立意义时提供可读标签。尊重系统“减少动态效果”设置。
- 所有表单、卡片和空状态都要检查键盘焦点、触控尺寸和文本对比度。

## 逐页推广顺序

1. **学生高频**：`MyStudy`、`Courses`、`Assignments`、`Vocabulary`、`Favorites`、`TaskPlans` 已做第一轮结构整理；下一轮在真实数据下细化“今天学什么、进度如何、下一步做什么”的信息顺序。
2. **沉浸学习**：`InteractiveText`、`VideoPlayer`、`PastPapers`、`AiQaPage` 等。内容优先，减少背景装饰，保持工具条稳定；小芽入口在阅读/答题时可收起。
3. **教师**：`Dashboard`、`Classes`、`TaskPlans` 已完成第一轮；后续处理 `Texts`、`MyStudents` 等。优先显示待处理任务、班级差异、进度与风险；避免为卡片造型牺牲数据密度。
4. **管理和运维**：管理员 `Dashboard` 和 `TaskPlans` 已完成第一轮；后续处理其他管理页面、活动页面、学校数据、日志、备份与功能开关。统一标题/筛选/批量操作/表格/弹窗模式；危险操作始终以清楚的语义提示区分。
5. **公开与用户端**：登录、公开文章、分享对话、创作者页面；沿用同一品牌语言，并保持未登录态清晰。

每批建议只处理一个页面类型，完成后合并小 PR；不得仅因 CSS 替换就标记页面“完成”。

## 验收清单

- 宽度：至少覆盖 375px 手机、768px 平板、1280px 桌面；检查安全区、底部导航、长标题、表格横向滚动、弹窗高度。
- 状态：加载、无内容、失败、禁用、表单报错、长文本、不同权限、功能开关关闭。
- 行为：现有路由跳转、筛选、分页、表单提交、上传、阅读和答题流程不退化。
- 可访问性：键盘焦点可见，图标按钮有标签，纯装饰不进入阅读顺序；减少动态效果时动画停用。
- 视觉：全站共用色彩和组件层级；学生页亲切但不干扰学习，后台页清楚而不松散。
- 自动检查：`cd frontend && npm run theme:audit && npm run build && npx vitest run`。临时排除既有失败可用 `npx vitest run --maxWorkers=1 --exclude tests/views/admin/Assignments.spec.js`。全量测试既有失败须作为单独问题记录，不与主题改动混合修复。

## 合并智能体功能分支时

`feat/learning-agent-mvp` 当前仍保存小芽的完整对话与悬浮入口。合并前先比较 `AgentMascot`、`LearningAgent`、`AgentCompanionWidget` 与这里的 `XyMascot`/主题变量；统一为一个形象来源，并让对话页复用全站变量。不要把视觉方案和智能体后端/数据库迁移捆绑为一个不可回滚的提交。
