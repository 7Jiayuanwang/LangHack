# 学习智能体内容发现路线图

> 状态：持续维护
> 当前策略：固定可信来源构建共享候选池，用户兴趣、专业和课表只在平台内参与排序。
> 本文只规划内容发现能力，不代表已决定采购或接入某家搜索服务。

## 当前阶段

当前默认外部来源包括 Wikipedia、arXiv、Europe PMC 和 DEV Community。平台定时抓取固定通用主题，形成共享候选池，再使用用户画像在本地重排。内容不足时回退到平台已有文章。

这一阶段优先验证：

- 推荐内容是否真的能提高阅读、收藏和完成率；
- 兴趣、专业、课表对内容匹配的贡献；
- 用户是否愿意把推荐内容交给智能体转写后继续学习；
- 不同来源的稳定性、质量和长期维护成本。

## 待办：将授权的外部文章导入站内精读

> 状态：Backlog / 尚未实现。先做受控小规模试点，不开放任意网址抓取。

目标是让学生能在站内完成“读原文 → 按水平转写 → 练习 → 问小芽”，而不只是阅读外部推荐的摘要。建议先从约 20–30 篇与学生兴趣、专业或课程相关的 Wikipedia 英文文章开始，使用官方接口获取正文；选题与发布前由运营/教师审核。

实施前需明确：

1. 逐篇核验正文及图片等素材的再利用许可；试点先只处理可授权的文本，不默认复制图片，也不把 arXiv、Europe PMC、DEV Community 的所有内容视为可导入。
2. 为文章及其难度改写版保存原文 URL、标题、作者/来源、许可证、抓取时间、原文版本、归属说明和改动说明，并在阅读页展示必要的署名与来源链接。
3. 建立独立于用户上传的导入、清洗、去重和审核流程；导入内容审核通过后才进入站内文章库与推荐流。
4. 复用现有转写、阅读、出题及小芽互动能力，并用阅读完成率、练习表现和用户反馈评估试点价值。
5. 如以后支持输入网址导入，先设计域名白名单、重定向与内网地址拦截、请求大小和超时限制；授权不明时仅保存摘要/链接，继续跳转原站阅读。

试点效果和维护成本验证后，再决定是否扩大来源与规模。

## 后续候选：利用搜索服务扩展内容发现

### 状态

- 优先级：Backlog / 暂不实现
- 是否启用：待固定来源方案积累真实使用数据后再决定
- 定位：补充候选内容，不替代可信固定来源

### 适用场景

当固定来源对影视、音乐、体育、旅行、商业、具体专业课程等主题覆盖不足时，可让平台围绕少量标准化主题词调用搜索服务，发现新的英文内容。

建议优先采用“共享搜索”：平台定时搜索通用主题并缓存结果，而不是每位用户每次打开页面都发起个性化搜索。

### 预期流程

```text
平台主题目录
  → 查询词规划（英文关键词、同义词、内容意图）
  → 搜索服务适配层
  → 结果标准化
  → 安全、质量与授权筛选
  → 共享候选池
  → 平台内使用兴趣/专业/课表进行个性化排序
  → 按用户英语水平转写并生成学习活动
```

### 查询词设计

- 用户兴趣、专业和课程名称先在平台内映射到受控主题目录；
- 对每个主题生成少量英文查询词，例如“主题 + explainer / latest research / practical guide”；
- 不把姓名、学号、原始课表、原始对话、错题内容等用户数据发送给搜索服务；
- 是否允许更细粒度的用户专属查询，后续单独做隐私和产品价值评估。

### 结果筛选

硬性过滤：

- HTTPS、允许访问、英文内容、URL 去重；
- 域名白名单/黑名单、恶意与成人内容过滤；
- 发布时间、页面可用性、标题和摘要完整性；
- 遵守来源的 robots、服务条款和内容授权，仅保存允许使用的元数据或链接。

质量排序：

- 查询相关性、来源可信度、时效性；
- 内容长度、结构完整性、信息密度和可转写性；
- 来源多样性，避免结果被单一网站占满；
- 与课程、专业或兴趣的本地匹配分；
- 用户后续的点击、完成、收藏和“不感兴趣”反馈。

### 搜索服务选型标准

后续选型时比较：

- 搜索结果质量和英文内容覆盖；
- API 稳定性、配额、费用和中国大陆服务器可用性；
- 是否允许缓存标题、摘要、缩略图和原链接；
- 隐私政策、日志保留和数据用途；
- 安全搜索、时间过滤、域名过滤和结果语言能力；
- 是否容易替换供应商，避免业务绑定到单一服务。

实现时应定义统一的 `SearchProvider` 接口，使具体搜索供应商可配置、可关闭、可替换。

### 启动条件

满足以下条件后再进入技术验证：

1. 固定来源方案已运行并获得真实点击、完成和收藏数据；
2. 能明确指出固定来源覆盖不足的主题，而不是笼统追求更多内容；
3. 已确定可接受的月度费用、缓存规则和隐私边界；
4. 建立人工评测集，用同一批主题比较不同搜索服务的前 5 条结果。

### 技术验证验收建议

- 前 5 条结果的人工相关率达到 80% 以上；
- 每个主题尽量覆盖至少 3 个可信域名；
- 不合适或不安全内容进入推荐页的比例低于 1%；
- 对外查询中不包含个人身份、原始课表、对话或学习记录；
- 搜索服务不可用时，固定来源和平台内容仍可正常推荐。

## 暂不做的事情

- 暂不接入具体搜索服务或新增相关配置；
- 暂不做开放式全网爬虫；
- 暂不开放全网抓取或长期存储未经授权的来源正文；仅在上述受控试点实施后导入已核验许可的文章；
- 暂不让大模型在没有可追溯规则的情况下自主选择和发布外部内容。
