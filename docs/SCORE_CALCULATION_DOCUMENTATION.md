# 分数计算规则文档

## 1. 任务分数计算规则

### 1.1 单个任务分数计算公式

任务分数由两部分组成：

```
基础分数 = 完成率 × 60（最高60分）
学习时长加分 = (学习时长 / 理想学习时长) × 40（最高40分）
总分数 = 基础分数 + 时长分数（最高100分）
```

**详细说明**：
- **完成率**：根据任务类型计算
  - 单词任务：已学习单词数 / 总单词数
  - 课文任务：已读课文数 / 总课文数（阅读时长需≥10分钟）
  - 单元任务：综合单词和课文进度
- **学习时长**：学生实际学习该任务的累计时长（分钟）
- **理想学习时长**：教师设置的任务理想学习时长（默认60分钟）
- **时长加分规则**：
  - 如果学习时长超过理想时长，按理想时长计算（不额外加分）
  - 如果学习时长不足，按比例计算

**示例**：
- 任务A：完成率80%，学习时长45分钟，理想时长60分钟
  - 基础分数 = 80% × 60 = 48分
  - 时长分数 = (45/60) × 40 = 30分
  - 总分数 = 48 + 30 = 78分

### 1.2 分数计算时机

- **自动计算**：当学生完成任务或学习时长达到阈值时自动触发
- **手动触发**：教师导出成绩时，如果学生没有分数记录，会自动计算
- **更新机制**：每次学习活动后，会更新任务进度，但分数不会实时更新（避免频繁计算）

## 2. 加权平均分计算规则

### 2.1 学生加权平均分（getStudentAverageScore）

**计算方式**：
```
加权平均分 = Σ(任务分数 × 任务权重) / Σ(任务权重)
```

**规则说明**：
1. **包含所有有分数记录的任务**：无论分数是多少（包括0分），都会计入加权计算
2. **权重来源**：从任务的 `weight` 字段获取，如果未设置则默认为1.0
3. **0分处理**：0分也是有效分数，表示未完成或未达标，会拉低平均分

**示例**：
- 任务A：分数80，权重1.0
- 任务B：分数60，权重1.5
- 任务C：分数0，权重1.0（未完成）

加权平均分 = (80×1.0 + 60×1.5 + 0×1.0) / (1.0 + 1.5 + 1.0) = 170 / 3.5 = 48.57分

### 2.2 导出成绩加权平均分（exportClassScores）

**当前计算规则（已修复）**：
```
加权平均分 = Σ(任务分数 × 任务权重) / Σ(任务权重)
```

**包含的任务**：
- **只计算有分数记录的任务**：无论分数是多少（包括0分），都计入加权平均分
- **不包含未开始的任务**：没有分数记录的任务不计入，因为学生还没有开始学习

**计算逻辑**：
1. 遍历班级所有任务
2. 对于每个任务，查找学生的分数记录
3. 如果分数记录不存在，尝试自动计算分数
4. 只有存在分数记录的任务才计入加权计算
5. 0分也计入（表示已开始但未完成或未达标）

**示例**：
- 任务A：分数80，权重1.0，有分数记录 → 计入
- 任务B：分数60，权重1.5，有分数记录 → 计入
- 任务C：分数0，权重1.0，有分数记录（已开始但未完成）→ 计入
- 任务D：无分数记录（未开始）→ 不计入

加权平均分 = (80×1.0 + 60×1.5 + 0×1.0) / (1.0 + 1.5 + 1.0) = 170 / 3.5 = 48.57分

**修复说明**：
- 修复前：所有任务（包括未开始的）都计入，未开始视为0分
- 修复后：只计算有分数记录的任务，未开始的任务不影响成绩

**重要提醒**：
- 0分任务**必须**计入加权平均分，因为0分也是有效分数（表示已开始但未完成）
- 如果0分任务被忽略，加权平均分会偏高（例如：99分任务的平均分会被误算为99，而不是包含0分后的59.4）
- 代码中已确保：`if (scoreRecord != null)` 时，无论 `finalScore` 是多少（包括0），都会计入

## 3. 今日学习时长计算规则

### 3.1 计算方式

```
今日学习时长（分钟）= Σ(今日所有学习记录的duration_seconds) / 60
```

### 3.2 数据来源

学习记录（`learning_records`表）中的 `duration_seconds` 字段，记录类型包括：
- `VIEW`：查看单词（默认10-30秒）
- `TEXT_VIEW`：查看课文（实际学习时长）
- `REVIEW`：复习单词（默认15秒）
- `TEST`：测试（实际测试时长）

### 3.3 异常值处理

- **单次记录过滤**：单次学习时长超过2小时（7200秒）的记录视为异常，不计算在内
- **总时长检查**：单日学习时长超过12小时（720分钟）会记录警告日志，用于排查数据异常
- **原因**：可能是系统错误或数据异常导致的异常值

### 3.4 可能的问题

**384分钟（约6.4小时）可能的原因**：
1. **数据异常**：存在大量学习记录，每条记录的时间累加
2. **记录重复**：同一学习活动被多次记录
3. **时长单位错误**：某些记录可能将分钟误存为秒，或秒数过大
4. **测试数据**：开发/测试过程中产生的异常数据

**建议检查**：
```sql
-- 检查今日学习记录
SELECT 
    id, 
    record_type, 
    duration_seconds, 
    created_time,
    word_id,
    text_id
FROM learning_records 
WHERE student_id = [学生ID] 
  AND DATE(created_time) = CURDATE()
ORDER BY duration_seconds DESC;

-- 检查异常记录（超过1小时）
SELECT COUNT(*) as count, SUM(duration_seconds) as total_seconds
FROM learning_records 
WHERE student_id = [学生ID] 
  AND DATE(created_time) = CURDATE()
  AND duration_seconds > 3600;
```

## 4. 分数存储

### 4.1 存储位置

分数存储在 `score_records` 表中，包含以下字段：
- `student_id`：学生ID
- `assignment_id`：任务ID
- `score`：分数（0-100）
- `full_score`：满分（默认100）
- `score_type`：分数类型（如"ASSIGNMENT"）
- `score_details`：分数详情（JSON格式，可选）
- `created_time`：创建时间
- `updated_time`：更新时间

### 4.2 分数更新

- **自动更新**：当任务进度或学习时长变化时，会重新计算分数
- **更新策略**：如果分数记录已存在，会更新现有记录；如果不存在，会创建新记录

## 5. 问题总结

### 5.1 当前问题

1. **今日学习时长384分钟不合理**
   - 可能原因：数据异常、记录重复、单位错误
   - 已添加异常值过滤（超过2小时不计算）
   - 需要进一步检查数据源

2. **导出成绩加权计算可能不合理**
   - 当前：所有任务（包括未开始的）都计入，未开始视为0分
   - 问题：未开始的任务不应该影响成绩
   - 需要确认业务需求：是否应该只计算已开始/已完成的任务

### 5.2 建议的优化

1. **学习时长优化**：
   - 添加更严格的异常值检测
   - 检查是否有重复记录
   - 添加学习时长的合理性验证（如单日不超过12小时）

2. **加权平均分优化**：
   - 明确区分"未开始"和"已完成但0分"
   - 只计算有学习活动的任务
   - 或者提供配置选项让教师选择计算方式
