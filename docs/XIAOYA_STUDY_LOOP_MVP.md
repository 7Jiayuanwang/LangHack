# 小芽连续对话与阅读复习闭环（2026-09-19）

## 本轮可用链路

1. 学生在小芽档案页获得平台文章与外部英文内容推荐。平台文章保留至少一个候选位，以便进入完整学习链路。
2. 平台文章进入现有站内阅读页：可使用已有难度版本、AI 出题和逐题解析。答题成功且 `attemptId` 已落库时，才提示“已记入复习记录”。
3. V55 `learner_review_tasks` 为每位学生、每篇平台文章持久保存一条下一次复习任务，迁移时回填已有答题。低于 80% 的最新练习在次日 07:00 建议复习；达标的首次练习 3 天后、重复练习 7 天后建议巩固。再次答题与计划更新在同一事务中完成。`/api/student/agent/study-loop` 展示完整到期任务数、最近具体错题及可核实的练习成绩；后两者最多分析最近 200 次答题，触及上限时页面会说明统计窗口。
4. 外部来源只展示来源 API 提供的短摘要与原文链接。学生可主动把摘要带入小芽对话请求难度提示、自测问题；目前不抓取或存储第三方完整正文，也不把摘要练习计入站内答题进度。
5. 用户上传的内容可打开“作文点评”窗口，先编辑待发送文本。只有点击发送后，最多 2000 字会通过现有 AI 问答接口交给平台配置的服务。
6. 从错题卡片跳转小芽时，答案只在当前浏览器标签页短暂预填，不放入 URL；进入对话页后即清除预填缓存，仍需学生点击发送。对话页可随时清除当前学习材料，避免在后续提问里继续携带。

## 对话与故障回退

- 每个平台对话复用一个 HiAgent QA 上游会话；只在 Redis 缓存不命中时创建。缓存仅保存用户 ID、平台对话 ID 与上游会话 ID 的映射，TTL 为 12 小时；Redis 故障时退化到单进程内缓存。
- HiAgent 在没有输出任何 SSE 字节前失败时，尝试运维端配置的 `chat` 提供商，并把一次性回答规范化为 `delta/done` 事件。若上游已输出部分内容，则只给出中断提示，绝不拼接另一模型的回答。
- 默认不会向回退提供商发送旧聊天正文。学生在小芽对话页主动勾选后，仅在故障回退发生时读取**同一会话**当前消息之前最近 8 条文字问答；每条最多 500 字、总计最多 3000 字，不读取旧的 `selected_text` / `article_context` 字段。勾选在切换对话后重置。未勾选或读取失败时，提示模型请学生复述必要背景。
- 历史文字回答本身仍可能包含学生曾分享的个人信息；页面对此明确提醒。当前提供商仍接收学生本轮主动提交的问题和学习材料。
- HiAgent 凭证、API 地址及 TLS 连通性仍必须在部署环境中核验。代码级回退不能替代真实服务可用性。

## 暂未覆盖

- 外部文章全文的合规获取、授权、站内适配及独立练习记录。
- 故障回退只有本轮回答和经授权的近期文字上下文；尚未建立备用提供商的持久会话，恢复 HiAgent 后也不能保证它理解备用提供商的回答。
- 独立的复习完成事件、学习效果的长期对照评估，以及超出平台文章的复习计划。
