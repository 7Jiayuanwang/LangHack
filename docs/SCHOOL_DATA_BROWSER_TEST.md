# 学校数据浏览页面测试文档

## 功能概述

运维数据浏览页面 (`/ops/school-data-browser`) 提供了强大的学校数据查询、筛选和导出功能。

## 测试环境

- **访问路径**: `/ops/school-data-browser`
- **权限要求**: OPS 或 ADMIN 角色
- **依赖服务**: 学校数据集成配置已完成

## 功能清单

### 1. 数据源切换

**测试步骤**:
1. 访问数据浏览页面
2. 查看顶部数据概览卡片（8个数据源）
3. 点击不同的数据源卡片切换

**预期结果**:
- 显示 8 个数据源的记录数统计
- 点击卡片后高亮显示，表格自动切换
- 数据源包括：
  - 行政班 (administrative_class)
  - 课程 (school_course)
  - 教学班/教师授课 (teacher_courses)
  - 课程安排 (course_schedule)
  - 选课记录 (course_selection)
  - 等级考试 (level_exam_scores)
  - 教学计划 (teaching_plans)
  - 学生课表 (student_schedule)

### 2. 筛选功能

**测试步骤**:
1. 点击"设置筛选条件"按钮
2. 在对话框中添加筛选条件
3. 选择字段、操作符、输入值
4. 添加多个条件组（AND/OR 关系）
5. 保存筛选条件

**预期结果**:
- 筛选对话框正常打开
- 可以添加/删除条件和条件组
- 支持的操作符：
  - `eq` (等于)
  - `contains` (包含)
  - `gte` (大于等于)
  - `lte` (小于等于)
  - `in` (在列表中)
- 保存后显示筛选摘要
- 表格数据根据筛选条件更新

**测试用例**:

#### 用例 1: 按学院筛选行政班
- 数据源: 行政班
- 条件: `collegeName` 包含 "外国语"
- 预期: 只显示外国语学院的班级

#### 用例 2: 按学年和学期筛选课程安排
- 数据源: 课程安排
- 条件组 1: `academicYear` 等于 "2023-2024" AND `semester` 等于 "1"
- 预期: 只显示 2023-2024 学年秋季学期的课表

#### 用例 3: 按成绩筛选等级考试
- 数据源: 等级考试
- 条件: `score` 大于等于 "425"
- 预期: 只显示成绩 ≥ 425 的记录

#### 用例 4: 复杂条件组合
- 数据源: 选课记录
- 条件组 1: `studentId` 包含 "2023" (2023级学生)
- 条件组 2: `credits` 等于 "2" OR `credits` 等于 "3"
- 预期: 显示 2023 级学生选修的 2 学分或 3 学分课程

### 3. 分页功能

**测试步骤**:
1. 查看表格底部分页器
2. 切换页码
3. 修改每页显示数量

**预期结果**:
- 显示总记录数
- 支持页码切换（上一页、下一页、跳转）
- 支持每页显示数量选择：10, 20, 50, 100, 200
- 切换后数据正确加载

### 4. 数据导出功能

**测试步骤**:

#### 4.1 导出当前页数据
1. 加载任意数据源
2. 点击"导出当前数据"按钮
3. 检查下载的 CSV 文件

**预期结果**:
- 成功下载 CSV 文件
- 文件名格式: `{数据源名称}_当前页_{日期}.csv`
- 文件包含当前页的所有记录
- 中文正常显示（UTF-8 BOM）
- 列名已翻译为中文

#### 4.2 导出全部数据
1. 加载任意数据源（确保总记录数 > 20）
2. 点击"导出全部数据"按钮
3. 等待批量加载完成
4. 检查下载的 CSV 文件

**预期结果**:
- 显示加载进度提示
- 分批加载所有数据（每批 100 条）
- 成功下载 CSV 文件
- 文件名格式: `{数据源名称}_全部数据_{日期}.csv`
- 文件包含所有记录（不受分页限制）
- 数据完整性验证：记录数 = 总记录数

#### 4.3 导出筛选后的数据
1. 设置筛选条件
2. 点击"导出全部数据"
3. 检查下载的 CSV 文件

**预期结果**:
- 导出的数据符合筛选条件
- 记录数 = 筛选后的总记录数

## 性能测试

### 大数据量测试

**测试场景**:
- 数据源记录数 > 1000
- 导出全部数据

**性能指标**:
- 分页加载时间 < 2s
- 导出 1000 条数据 < 10s
- 导出 10000 条数据 < 60s

### 筛选性能测试

**测试场景**:
- 复杂筛选条件（3+ 条件组）
- 大数据量筛选

**性能指标**:
- 筛选查询响应时间 < 3s
- 筛选结果准确

## 边界测试

### 空数据测试
- 数据源无记录时显示"暂无数据"
- 导出按钮禁用

### 权限测试
- 非 OPS/ADMIN 角色无法访问
- 重定向到登录页或 403 页面

### 错误处理
- 网络错误时显示友好提示
- 后端错误时不崩溃
- 导出失败时提示用户
