# 教师班级学情概览

教师可从“班级管理”的班级名称／“学情”按钮进入 `/teacher/classes/:classId`；教学首页的“查看详情”也通向同一页。“我的授课”中的学校教学班若已经同步为平台班级，会显示“查看班级学情”；尚未关联的班级只引导前往班级管理，不显示猜测数据。

## 数据口径

- 后端接口：`GET /api/teacher/classes/{classId}/learning-overview`。只允许已登录教师查看 `classes.teacher_id` 属于自己的班级，先校验归属再查询学生数据。
- 统计对象：该平台班级当前在册、未删除的学生。数据覆盖这些学生在**全平台**的阅读和练习，不限定为该课程的作业；因此不能将图表解读为作业完成率或考试成绩。
- 时间：最近四个自然周，包含尚未结束的本周，从三周前周一至今天。接口返回 `windowStart`、`windowEnd`。
- 阅读：`text_learning_records.start_time` 落在时间段内的会话；“阅读人数”是不同学生数，“阅读篇数”是不同平台文章数。会话开始即计入，不表示读完。
- 阅读题：`student_ai_quiz_attempts.submitted_time` 落在时间段内的提交；正确率是 `SUM(correct_count) / SUM(total_questions)`，四舍五入为整数百分比，没有有效答题时为 `null` 而不是 0%。分布图每名学生只计一次，依据其区间内全部答题的展示正确率分组；“未答题”单列。
- “有站内学习记录”指至少有阅读会话或阅读题提交；没有记录只代表本统计范围内缺少这两类证据，不代表学生没有线下学习。每周图的阅读和答题人数分别去重，可能重叠。
- 学生明细只包含姓名／账号、阅读与答题汇总及最近记录时间；不读取或返回小芽对话、作文正文、兴趣等私密内容。

## 当前边界

这是可核实的基础学情面板。尚未把作业完成、词汇复习、错题知识点、作文表现合并为统一指标；不能据此推断学生的综合英语能力。班级成员变动后，页面展示的是**当前成员**在统计时间段内的平台行为。页面支持空班、无记录、接口错误与重试，不生成模拟数据。
