# 学校数据浏览页面使用指南

## 概述

学校数据浏览页面是运维人员查询、筛选和导出已同步学校数据的专用工具。支持 8 种数据源的灵活查询和批量导出。

## 访问方式

1. 使用 OPS 或 ADMIN 账号登录系统
2. 进入运维面板
3. 点击导航栏的"数据"或"数据浏览"
4. 或直接访问: `https://your-domain/ops/school-data-browser`

## 页面布局

```
┌─────────────────────────────────────────────────────┐
│  数据概览卡片（8个数据源统计）                        │
├─────────────────────────────────────────────────────┤
│  同步控制区（同步模式、筛选、同步按钮）                │
├─────────────────────────────────────────────────────┤
│  链式拉取卡片（如果启用）                             │
├─────────────────────────────────────────────────────┤
│  导出控制区（导出当前页、导出全部）                    │
├─────────────────────────────────────────────────────┤
│  数据表格（Tab 切换不同数据源）                       │
├─────────────────────────────────────────────────────┤
│  分页器                                              │
└─────────────────────────────────────────────────────┘
```

## 功能详解

### 1. 数据源选择

**方式一：点击概览卡片**
- 页面顶部显示 8 个数据源的记录数统计卡片
- 点击任意卡片即可切换到对应数据源
- 当前选中的卡片会高亮显示

**方式二：切换 Tab**
- 表格上方有 8 个 Tab 标签
- 点击标签切换数据源

**8 种数据源**:
1. **行政班**: 学生行政班级信息
2. **课程**: 学校课程基础信息
3. **教学班**: 教师授课班级（含教师授课数据）
4. **课程安排**: 课表时间地点
5. **选课记录**: 学生选课信息
6. **等级考试**: 四六级成绩
7. **教学计划**: 专业培养方案
8. **学生课表**: 学生个人课表

### 2. 筛选数据

#### 2.1 打开筛选对话框

点击"设置筛选条件"按钮，打开筛选条件编辑器。

#### 2.2 添加筛选条件

**基本操作**:
1. 选择字段（如：学院名称、学年、学期等）
2. 选择操作符（等于、包含、大于等于等）
3. 输入筛选值
4. 点击"+ 添加条件"可添加更多条件

**条件组**:
- 每个条件组内的条件可以是 AND（且）或 OR（或）关系
- 点击"+ 添加条件组"可创建多个条件组
- 条件组之间是 AND 关系

#### 2.3 操作符说明

| 操作符 | 说明 | 示例 |
|--------|------|------|
| 等于 (eq) | 精确匹配 | `学年 = 2023-2024` |
| 包含 (contains) | 模糊匹配 | `学院名称 包含 外国语` |
| 大于等于 (gte) | 数值比较 | `成绩 >= 425` |
| 小于等于 (lte) | 数值比较 | `学分 <= 3` |
| 在列表中 (in) | 多值匹配 | `学期 in 1,2` |

#### 2.4 筛选示例

**示例 1: 查询外国语学院的行政班**
```
数据源: 行政班
条件: collegeName 包含 "外国语"
```

**示例 2: 查询 2023-2024 学年秋季学期的课表**
```
数据源: 课程安排
条件组 (AND):
  - academicYear 等于 "2023-2024"
  - semester 等于 "1"
```

**示例 3: 查询四六级通过的学生**
```
数据源: 等级考试
条件: score 大于等于 "425"
```

**示例 4: 查询 2023 级学生的 2-3 学分课程**
```
数据源: 选课记录
条件组 1 (AND):
  - studentId 包含 "2023"
条件组 2 (OR):
  - credits 等于 "2"
  - credits 等于 "3"
```

#### 2.5 保存和应用筛选

1. 设置完筛选条件后，点击"保存"按钮
2. 对话框关闭，筛选条件摘要显示在同步控制区
3. 表格数据自动更新为筛选后的结果
4. 分页器显示筛选后的总记录数

#### 2.6 重置筛选

点击"重置筛选"按钮可清除所有筛选条件，恢复显示全部数据。

### 3. 数据导出

#### 3.1 导出当前页数据

**适用场景**: 快速导出当前查看的数据

**操作步骤**:
1. 浏览到需要导出的数据页
2. 点击"导出当前数据 (N 条)"按钮
3. 浏览器自动下载 CSV 文件

**文件命名**: `{数据源名称}_当前页_{日期}.csv`

**示例**: `行政班_当前页_2024-05-05.csv`

#### 3.2 导出全部数据

**适用场景**: 导出完整数据集或筛选后的全部数据

**操作步骤**:
1. 可选：设置筛选条件
2. 点击"导出全部数据 (N 条)"按钮
3. 等待系统分批加载数据（会显示进度提示）
4. 浏览器自动下载 CSV 文件

**文件命名**: `{数据源名称}_全部数据_{日期}.csv`

**示例**: `选课记录_全部数据_2024-05-05.csv`

**注意事项**:
- 导出大量数据（>1000 条）时需要等待一段时间
- 系统会显示加载进度（如："已加载 500 / 2000 条数据..."）
- 导出的数据会自动应用当前的筛选条件
- 不受分页限制，导出所有符合条件的记录

#### 3.3 CSV 文件说明

**编码**: UTF-8 with BOM（支持 Excel 直接打开中文）

**列名**: 已翻译为中文，便于阅读

**数据格式**:
- 日期: YYYY-MM-DD
- 学期: 1=秋, 2=春
- 星期: 一、二、三、四、五、六、日
- 布尔值: 是/否、通过/未通过

**打开方式**:
- Excel: 直接双击打开
- WPS: 直接双击打开
- Google Sheets: 导入 CSV 文件

### 4. 数据同步

#### 4.1 同步模式

**全量同步**:
- 从学校数据源拉取全部数据
- 覆盖本地已有数据
- 适用于初次同步或数据修复

**增量同步**:
- 只拉取更新的数据（基于 updated_at 字段）
- 不影响未变更的数据
- 适用于日常数据更新

#### 4.2 同步操作

1. 选择数据源（点击概览卡片或切换 Tab）
2. 选择同步模式（全量/增量）
3. 可选：设置筛选条件（只同步符合条件的数据）
4. 点击"同步当前数据源"按钮
5. 等待同步完成

**同步后**:
- 数据概览自动更新
- 表格数据自动刷新
- 显示同步成功提示

#### 4.3 教学班联合同步

对于"教学班 / 教师授课"数据源，可以勾选"联合同步相关数据源"选项，系统会同时同步 `teaching_class` 和 `teacher_courses` 两个数据源。

### 5. 链式拉取（高级功能）

**功能说明**: 按学院链式拉取课程 → 教师 → 学生 → 绑定关系

**前置条件**: 功能开关 `ops.school_data_chain_fetch` 已启用

**操作步骤**:
1. 在"按学院链式拉取"卡片中输入学院名称（如：外国语学院）
2. 选择匹配模式：
   - **精确匹配**: 学院名称必须完全一致
   - **模糊匹配**: 学院名称包含输入的关键词
3. 点击"执行链式拉取"按钮
4. 等待拉取完成，查看结果摘要

**结果摘要**:
- 课程数: 拉取的课程记录数
- 学生数: 拉取的学生记录数
- 教师数: 拉取的教师记录数
- 绑定数: 创建的师生绑定关系数
- KCBH 支持: 上游 API 是否支持按课程班号筛选

### 6. 分页浏览

**分页控件**:
- 总记录数显示
- 每页显示数量选择: 10, 20, 50, 100, 200
- 上一页 / 下一页按钮
- 页码快速跳转

**操作技巧**:
- 大数据量浏览时，建议先设置筛选条件缩小范围
- 需要查看全部数据时，使用"导出全部数据"功能
- 每页显示数量会影响加载速度，建议根据网络情况调整

## 常见问题

### Q1: 为什么看不到数据？

**可能原因**:
1. 学校数据尚未同步
2. 筛选条件过于严格，没有匹配的记录
3. 数据源配置未完成

**解决方法**:
1. 检查数据概览卡片，确认记录数 > 0
2. 点击"重置筛选"清除筛选条件
3. 前往"学校数据配置"页面检查配置

### Q2: 导出的 CSV 文件乱码怎么办？

**原因**: Excel 版本较旧，不支持 UTF-8 BOM

**解决方法**:
1. 使用 WPS 或 Google Sheets 打开
2. 或在 Excel 中选择"数据" → "从文本/CSV" → 选择 UTF-8 编码导入

### Q3: 导出全部数据时间很长？

**原因**: 数据量较大，需要分批加载

**建议**:
1. 先设置筛选条件，缩小导出范围
2. 分批导出（如按学年、学期分批）
3. 在网络较好的时段操作

### Q4: 筛选条件不生效？

**检查项**:
1. 确认已点击"保存"按钮
2. 检查筛选值是否正确（注意大小写、空格）
3. 检查操作符是否选择正确
4. 查看筛选摘要，确认条件已应用

### Q5: 同步失败怎么办？

**排查步骤**:
1. 检查学校数据源配置是否正确
2. 点击"测试连接"验证连接
3. 查看后端日志获取详细错误信息
4. 联系系统管理员

## 最佳实践

### 1. 日常数据查询

```
1. 选择数据源
2. 设置筛选条件（如学年、学期）
3. 浏览数据
4. 需要时导出当前页
```

### 2. 数据分析导出

```
1. 设置复杂筛选条件
2. 确认筛选结果正确
3. 导出全部数据
4. 使用 Excel/WPS 进行数据分析
```

### 3. 定期数据同步

```
1. 每天执行一次增量同步
2. 每周执行一次全量同步
3. 学期初/学期末执行全量同步
4. 同步后检查数据概览，确认记录数正常
```

### 4. 数据质量检查

```
1. 导出全部数据
2. 检查必填字段是否有空值
3. 检查数据格式是否正确
4. 检查数据一致性（如学分、学时）
5. 发现问题及时反馈
```
