# 活动计分规则激励优化方案

## 现状问题

当前计分系统结构为 **固定分值 × 完成次数**，配合 `dailyLimit` / `maxCompletions` 做上限控制。排名有个人/班级/学院三级，但存在以下不足：

- 班级排名按总分排序，人多的班天然优势，参与率低的班没有动力
- 没有连续性奖励，突击一天和每天坚持获得的积分一样
- 缺乏社交压力和协作目标，个人排名只激励头部学生

---

## 一、个人维度

### 1. 连续学习加成（Streak Bonus）

连续多天有学习行为时，获得积分系数加成。按管理员配置的周期自动归零，所有人同一起跑线。

**管理员可配置项：**

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| 是否启用 | 活动级别开关 | 开启 |
| 重置周期（天） | 多少天归零一次（以活动开始日为锚点） | 7 天 |
| 加成阶梯 | 自定义"连续第N天→加成X%"列表 | 第2天+5%，第3天+10%...第7天+30% |
| 封顶系数 | 最大加成倍率（由阶梯最大值自动计算） | ×1.3 |

**默认阶梯（管理员可在活动表单中自由增删改）：**

| 连续天数 | 加成百分比 | 积分系数 |
|---------|-----------|---------|
| 第 1 天 | 0% | ×1.00 |
| 第 2 天 | 5% | ×1.05 |
| 第 3 天 | 10% | ×1.10 |
| 第 4 天 | 15% | ×1.15 |
| 第 5 天 | 20% | ×1.20 |
| 第 6 天 | 25% | ×1.25 |
| 第 7 天 | 30% | ×1.30（封顶） |

管理员可以完全自定义，例如：
- "3天一重置，第2天+10%，第3天+20%"（短周期高强度）
- "14天一重置，第3天+5%，第7天+15%，第14天+50%"（长周期鼓励坚持）

**规则说明：**

- "活跃日"定义：当日至少有一个任务达标完成（`isCompleted = true`）
- 重置周期以活动开始日期为锚点，每隔指定天数自动归零
- 容错机制：断签 1 天系数回退一级，断签 2 天及以上本周期系数归零

### 2. 社交可见性

- **每周学习之星：** 周积分 Top 3 展示

## 二、班级维度

### 1. 班级排名公式优化

**当前：** 按班级总分排序（人多的班碾压小班）

**改为（两种方案对比）：**

**参与率定义（通用）：**

两种计算方式可选：

**方式 1：活跃人数占比（只关心"来没来"）**

```
班级周参与率 = 本周有过活跃的人数 / 班级实际总人数
```

只要本周至少学了 1 天就算"参与"。40 人的班有 30 人本周至少学了 1 天，参与率 = 30/40 = 0.75。

优点：简单直观，容易达到较高参与率，激励"至少来一次"。
缺点：来了一天和来了七天没有区别。

**方式 2：活跃天数密度（关心"来了几天"）**

```
班级周参与率 = 全班所有人本周活跃天数之和 / (班级实际总人数 × 7)
```

既鼓励更多人参与，也鼓励每个人多学几天。40 人的班本周活跃天数加起来 120 天，参与率 = 120 / 280 = 0.43。

优点：区分度更高，每天坚持的班和只来一天的班差距明显。
缺点：数值普遍偏低（全班每人每天都学才能达到 1.0），需要配合归一化使用。

**通用规则：**
- "活跃天"定义：当日至少有一个任务达标完成（`isCompleted = true`），仅产生少量得分但未达标不算
- "班级实际总人数"取自学校数据（school_student 表），不是报名人数
- 没报名的同学也计入分母，未活跃天数按 0 计
- 按周计算，配合周排名

**方案 A：归一化加权（推荐）**

```
归一化人均积分 = 本班人均积分 / 所有班中最高人均积分             （范围 0~1）

班级综合得分 = 归一化人均积分 × 人均权重 + 班级周参与率 × 参与率权重
```

**管理员可配置项：**

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| 人均积分权重 | 人均积分在综合得分中的占比 | 0.6 |
| 参与率权重 | 参与率在综合得分中的占比 | 0.4 |

两个权重之和应为 1.0，管理员可根据活动目标调整（如更看重参与度可设为 0.4:0.6）。

示例（默认 0.6:0.4）：
- A 班：人均 200（全场最高），周参与率 0.43 → 得分 = 1.0×0.6 + 0.43×0.4 = 0.77
- B 班：人均 150，周参与率 0.80 → 得分 = 0.75×0.6 + 0.80×0.4 = 0.77

参与率高的班能弥补人均积分差距。两个维度量级相同，权重配比真正生效。

**方案 B：直接人均积分排序**

```
班级得分 = 人均积分
```

排名直接按人均积分降序。班级周参与率不参与排名计算，仅作为前端展示信息。

优点：简单直观，人均积分已经消除了班级人数差异。
缺点：对参与率没有直接激励，"一个人卷"也能撑起全班排名。

排名按综合得分降序，公平反映班级整体学习氛围。

**参与率口径说明：** 班级实际总人数取自学校数据（school_student 表），按周计算活跃天数占比，未报名或未活跃的同学均计入分母。

### 2. 班级活跃热力图

展示"今日本班有 X 人在学习"，营造"大家都在学"的氛围感。

## 三、激励逻辑总结

| 目标人群 | 激励手段 | 预期行为变化 |
|---------|---------|------------|
| 完全不动的人 | 班级排名参与率权重 + 活跃热力图 | 被同班社交压力推动开始学习 |
| 偶尔学一下的人 | 连续学习加成 | 每天都打开学一点 |
| 中间层（想追但觉得追不上） | 连续加成 + 周排名归零 | 每周都是新机会，坚持就能追 |
| 头部卷王 | 周学习之星 | 荣誉激励保持活跃 |

---

## 四、实现优先级

| 优先级 | 功能 | 改动量 | 预期效果 |
|-------|------|--------|---------|
| P0 | 班级排名公式改为人均+参与率加权 | 小 | 直接拉动参与率 |
| P1 | 连续学习加成 | 中 | 养成每日习惯 |
| P1 | 社交可见性（排名变化、班级热力图） | 中 | 激活中间层学生 |
