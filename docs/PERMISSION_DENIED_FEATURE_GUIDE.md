# 权限拒绝提示功能指南

## 功能概述

根据统一身份认证对接要求，当用户没有LangHack英语学习平台的使用权限时，系统会显示包含系统主管部门联系方式的温馨提示界面。

## 功能特性

### 后端实现
- 在`SsoUserMappingService`中修改权限拒绝消息
- 包含完整的联系方式：计算机与信息工程学院43019235
- 支持SSO登录和普通登录的权限检查

### 前端实现
- 创建了`PermissionDenied.vue`组件
- 集成到登录页面和SSO回调页面
- 自动识别权限拒绝错误并显示相应提示

## 实现细节

### 1. 后端修改

#### 文件：`backend/src/main/java/com/english/sso/service/SsoUserMappingService.java`

修改了三个权限拒绝场景的消息内容：

```java
// 原来的消息
"您的账号正在审批中，请联系管理员"

// 修改后的消息
"对不起，您无权使用LangHack英语学习智能体平台。\n如有疑问请致电：计算机与信息工程学院43019235"
```

### 2. 前端组件

#### 文件：`frontend/src/components/PermissionDenied.vue`

创建了权限提示组件，包含：
- 温馨提示图标和标题
- 主要拒绝信息
- 联系方式显示
- 操作按钮（返回登录、重新登录）

#### 主要特性：
- 响应式设计，支持移动端
- 美观的UI设计，符合平台风格
- 可配置的联系方式信息

### 3. 页面集成

#### SSO回调页面：`frontend/src/views/public/SsoCallback.vue`
- 检测权限拒绝错误消息
- 解析并显示联系方式
- 区分普通错误和权限拒绝

#### 登录页面：`frontend/src/views/Login.vue`
- 集成权限提示组件
- 处理普通登录的权限拒绝
- 支持弹窗式显示

## 配置说明

### 联系方式配置

联系方式信息可以在以下位置修改：

1. **后端消息**：`SsoUserMappingService.java`
2. **前端组件默认值**：`PermissionDenied.vue`
3. **页面特定配置**：各个使用组件的页面

### 自定义联系方式

如需修改联系方式，请更新以下文件：

```javascript
// PermissionDenied.vue
const props = defineProps({
  contactPhone: {
    type: String,
    default: '43019235'  // 修改此处
  },
  contactDepartment: {
    type: String,
    default: '计算机与信息工程学院'  // 修改此处
  }
})
```

## 故障排查

### 常见问题

1. **权限提示不显示**
   - 检查错误消息是否包含关键词"无权使用"或"计算机与信息工程学院"
   - 验证前端组件是否正确导入

2. **联系方式错误**
   - 检查后端消息格式是否正确
   - 验证前端解析逻辑是否正常

3. **样式显示异常**
   - 检查CSS样式是否正确加载
   - 验证响应式断点是否生效

### 调试方法

1. **浏览器控制台**：查看JavaScript错误和网络请求
2. **后端日志**：检查SSO认证流程日志
3. **前端调试**：使用Vue DevTools检查组件状态
