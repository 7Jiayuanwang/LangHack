## 🚀 新功能：密码更新

现在导入脚本支持 `--update-password` 参数，可以更新已存在用户的密码。

### 使用方法

```bash
# 更新已存在用户的密码
python3 scripts/import_class_students.py \
  --excel "25土管名单新.xls" \
  --class-name "2025级土地资源管理3班" \
  --course-id 1 \
  --teacher-id 1 \
  --filter-class "25土管3" \
  --update-password
```

### 参数说明

- `--update-password`: 如果用户已存在，更新其密码为新的默认密码（完整学号）
